# Cybersecurity Awareness Assistant - Part 2

## Project Overview

The Cybersecurity Awareness Assistant is a C# WPF desktop application designed to help South African citizens learn about basic cybersecurity risks and safe online practices.

Part 2 updates the original command-line chatbot from Part 1 by providing a graphical user interface (GUI).

## Technologies Used

- C#
- .NET 10
- Windows Presentation Foundation (WPF)
- Visual Studio Code
- Git and GitHub

## Features

- User name personalisation
- Cybersecurity awareness chatbot
- Phishing information
- Password security information
- Online scam awareness
- Safe browsing guidance
- Malware information
- Social engineering information
- Online privacy guidance
- OTP safety information
- Quick topic buttons
- Send button
- Clear conversation button
- Press Enter to send a message
- Cybersecurity tips panel
- ASCII-style cybersecurity logo
- Separate chatbot logic using `Chatbot.cs`
